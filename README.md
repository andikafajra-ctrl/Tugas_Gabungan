🛠️ Teknologi yang Digunakan

Teknologi yang digunakan dalam pengembangan website ini meliputi:


HTML
Digunakan untuk membangun struktur dan elemen dasar halaman website.


CSS
Digunakan untuk mengatur tampilan dan layout website, termasuk warna, font, dan responsivitas.
Seluruh styling ditulis pada file style.css.


JavaScript
Digunakan untuk menambahkan interaksi pada website, seperti:


Menu toggle


Slider


Pergantian gambar featured

Seluruh script ditulis pada file script.js.


Font Awesome (CDN)
Digunakan untuk menampilkan ikon pada website tanpa perlu menyimpan file ikon secara lokal.


Google Fonts (Nunito)
Digunakan sebagai font utama untuk meningkatkan tampilan dan keterbacaan teks.


Web Browser
Google Chrome atau Mozilla Firefox (versi terbaru).




⚙️ Cara Menjalankan Program


1️⃣ Menjalankan Tanpa Server



Project ini bersifat static website, sehingga dapat dijalankan tanpa server.


Langkah-langkah:


Buka folder project


Klik dua kali file index.html


Website akan terbuka di browser


🚀 Cara Menggunakan Aplikasi


Buka halaman utama website


Gunakan menu navigasi untuk berpindah halaman


Gunakan slider atau fitur interaktif yang tersedia


Website merespons interaksi menggunakan JavaScript


⚠️ Catatan Penting


Pastikan koneksi internet aktif untuk memuat Font Awesome CDN dan Google Fonts


Gunakan browser versi terbaru agar tampilan dan fitur berjalan optimal


Struktur folder sebaiknya tidak diubah
